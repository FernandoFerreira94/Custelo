# Specs

Feature complexa ganha um arquivo aqui **antes** do codigo, no formato
`specs/<feature>.md`: requisitos, criterios de aceite, o que muda e o que nao
muda.

Telas nao vivem aqui — o ID (`REC-003`) e a spec canonica no Notion, com indice
em `docs/product/screen-map.md` e tracker em `docs/product/screen-tracker.md`.

Vazio de proposito: a primeira spec nasce com a primeira feature de I2.
